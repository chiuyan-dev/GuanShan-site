01

适用范围与基本原则

本政策说明 QIURAN NING（以下称“开发者”）如何在观山／观山罗盘 iPhone App、配套支持网站及你主动发起的支持沟通中处理信息。适用于当前 0.2 系列及延续相同行为的后续版本；若功能或数据处理方式改变，将相应更新本政策。

观山的主要工作在设备上完成：读取系统朝向和运动状态，计算坐山朝向，显示盘层并保存你的界面偏好。当前 App 无需注册或登录，不设用户账号，不接入广告、行为分析、跨 App 追踪或第三方统计 SDK，不将传感器读数发送给开发者服务器。

“在设备上处理”并不意味着系统完全不接触数据。Apple 提供的定位、系统备份、诊断和 TestFlight 服务按其自身规则运行；你访问本网站或发送支持邮件也会产生相应网络信息。以下分别说明。

02

在设备上使用哪些信息

朝向、时间与系统估计误差
应用通过 Core Location 获取磁北、可用的真北、朝向样本时间及系统估计误差，用于显示角度、判断数据是否过期、计算山向和提示测量状态。这些数据用于当前测量，不用于识别个人或建立长期活动画像。
当前位置
在你触发真北或定位功能并授予权限后，应用可读取系统位置及位置精度，用来判断定位可用性并支持真北、磁偏角显示。应用不要求你填写地址，不上传经纬度，不保存连续位置轨迹。已授权时，前台运行可能持续接收位置更新；切回磁北并不等同于撤回定位授权。
运动与磁场状态
应用通过 Core Motion 读取重力、转动速率、磁场和校准状态，计算倾斜及环境提示。它不使用这些信息分析健康状况、日常运动习惯或广告兴趣。
系统语言与本地设置
首次使用时读取系统首选语言，以选择默认简体或繁体显示。你的手动语言、盘层组合、震感模式、光影及页头位置偏好通过系统本地偏好存储保存，不发送给开发者。
设备运行时间
设置中的连续点击入口使用设备运行时间计算点击间隔。这项信息仅用于 App 内事件计时，不用于设备指纹识别或跨应用追踪。
03

权限、选择与撤回

定位权限由 iOS 管理。应用仅在相关功能需要时请求使用期间定位，不请求为了营销而定位，也不提供后台追踪功能。拒绝定位不会阻止可用的磁北功能，但真北和磁偏角可能无法显示。

你可以随时在 iPhone 的系统设置中调整定位权限；系统提供的运动与健身、分析共享等选项也由你控制。不同 iOS 版本与设备显示的选项可能不同。如果关闭某项功能所需权限或设备不支持相关数据，应用会提示不可用或留空。

应用进入后台会停止位置、朝向与运动更新。撤回权限后不会继续通过该权限获取新的数据；当前会话中已收到的临时数据可能在更新、状态重置或进程结束时被替换或释放。你无需创建账号，也无需提交个人联系方式来使用罗盘。

04

保存位置、期限与删除

实时读数：普通测量数据主要保留在运行内存中，用于当前显示与有效性判断。锁定读数仅保留当前会话快照，不建立长期测量档案。应用不会把位置轨迹或连续朝向历史写入开发者数据库。

本地偏好：界面与盘层设置在本机持续保存，直到你修改设置或删除相应应用数据。iOS 可能按照你的设备备份设置备份应用容器；开发者不运营独立的同步服务器，也无法远程读取或删除你的系统备份。

本地诊断：在专门的诊断启动方式下，应用可以生成本地诊断文件，包含采样次数、读数、误差、传感器状态和时间等排查信息。该文件不会自动上传；普通使用没有自动发送诊断文件的功能。只有你主动提供时，开发者才会收到相应内容。

删除方式：在 iOS 存储设置中使用“删除 App”可移除其本地应用数据；“卸载 App”可能保留文稿与数据。备份副本由你在 Apple 的相关设置中管理，恢复旧备份后部分设置也可能恢复。应用没有账号，因此没有单独的账号注销步骤。

05

主动联系时的信息

当你向支持邮箱发送邮件时，开发者会收到发件地址、邮件正文，以及你选择附加的截图或文件。用途是回复问题、核实故障和处理你提出的请求；不会因此将你加入营销名单，也不会把邮件内容出售给广告方。

请尽量只提供设备型号、系统版本、App 版本和复现步骤。不要发送密码、验证码、身份证件、支付资料或与问题无关的精确位置。如误发了敏感内容，可继续通过同一邮箱提出删除请求。

支持沟通仅在处理请求及合理后续排查所需期间保留；不再需要时删除或去除可识别信息。若法律要求保留必要记录，或存在尚未解决的争议，可保留必要部分。你可以询问相关记录的处理情况，并请求删除不再必要的支持邮件或附件。

06

Apple、网站托管与外部链接

Apple 服务：定位与传感器由 Apple 系统框架提供；系统可能根据你的设置处理定位、备份或诊断信息。通过 TestFlight 测试时，Apple 可能收集并向开发者提供测试反馈、崩溃、安装或使用统计等信息。开发者收到后仅用于测试、故障排查和改进应用。你可查阅 Apple 隐私政策及 TestFlight 中的说明。

本支持网站：页面托管于 GitHub Pages。我们未在页面中加入广告、统计像素、分析脚本、注册表单或追踪 Cookie，也不使用浏览器本地存储建立访问画像。访问网页时，GitHub 作为托管服务会接收网络请求；GitHub 说明会为安全目的记录访问者 IP 地址。其处理方式见 GitHub 隐私声明。

邮件服务：主动发出的支持邮件经由你选择的邮件服务和支持邮箱服务商传递与保存。该处理由相应服务的隐私规则约束，开发者只使用收到的内容处理你的请求。

资料链接：应用和本网站含有测量资料、平台帮助或政策链接。打开后会连接相应网站，对方可能接收 IP 地址、浏览器信息及网络请求。外部网站的内容和隐私实践由其运营方负责，发送信息前请查看其说明。

07

共享、安全与跨地区处理

当前 App 没有向开发者后台上传测量数据的接口，不出售或出租你的个人信息，不用于广告追踪。对于主动支持沟通，只有处理问题所必需的人员或提供传递、存储的服务才可能接触内容；如依法必须回应合法请求，仅提供所需范围内的信息。

应用使用 iOS 的权限机制和应用容器保存本地数据；网站使用 HTTPS 访问。请保护设备密码、Apple 账户和邮件账户。任何设备或网络系统都无法承诺绝对安全，因此反馈时应避免发送不必要的敏感信息。

App 的测量处理在你的设备上完成。网站托管、Apple 平台和邮件服务可能在你所在地区以外的服务器上处理网络或支持沟通信息；开发者不建立独立的跨境测量数据库。相关平台的具体处理安排由其政策说明。

08

你的请求与未成年人信息

你可控制系统权限，修改本地偏好，删除应用及本地数据，并就主动发送给开发者的支持资料提出访问、更正或删除请求。由于开发者不能读取你的设备数据，涉及设备偏好、Apple 备份或平台诊断的操作，需要你在对应系统或服务中完成。

为避免误删他人信息，处理邮件记录请求时可能需要你从原联系邮箱发起或提供足以定位该次沟通的说明；不会仅为处理普通支持请求索取身份证件。无法立即完成的请求，会说明原因和可行处理方式。

应用不针对未成年人建立资料或投放定向广告，也不要求用户填写出生日期。未成年人发送反馈前应获得监护人的适当协助。若你认为支持邮件中包含不应保留的未成年人信息，请告知以便核查和处理。
