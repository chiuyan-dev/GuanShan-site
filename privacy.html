01

适用范围与基本原则

本政策说明 QIURAN NING（以下称“开发者”）如何在观山／观山罗盘 iPhone App、配套支持网站及你主动发起的支持沟通中处理信息。本页涵盖罗盘与可选奇门模块；较早版本可能没有其中部分功能，具体以安装版本为准。若功能或数据处理方式改变，将相应更新本政策。

观山的主要工作在设备上完成：读取系统朝向和运动状态，计算坐山朝向，显示盘层并保存你的界面偏好；启用奇门模块后，根据起局时间、规则及可选地点在本机计算盘局。奇门默认关闭。当前 App 无需注册或登录，不设用户账号，不接入广告、行为分析、跨 App 追踪或第三方统计 SDK，不将传感器读数发送给开发者服务器。

“在设备上处理”并不意味着系统完全不接触数据。Apple 提供的定位、系统备份、诊断和 TestFlight 服务按其自身规则运行；你访问本网站或发送支持邮件也会产生相应网络信息。以下分别说明。

02

在设备上使用哪些信息

朝向、时间与系统估计误差
应用通过 Core Location 获取磁北、可用的真北、朝向样本时间及系统估计误差，用于显示角度、判断数据是否过期、计算山向和提示测量状态。这些数据用于当前测量，不用于识别个人或建立长期活动画像。
当前位置
在你触发真北、罗盘定位或奇门定位功能并授予权限后，应用可读取系统位置及位置精度，用于真北、磁偏角或奇门起局地。奇门也可由你手动选择地区、输入经纬度；启用真太阳时则在本机使用经度校正。坐标不上传给开发者，不用于保存连续位置轨迹；成功起局使用的地点会随参数在本机保存。罗盘的已授权前台会话可能持续接收位置更新，切回磁北并不等同于撤回定位授权。
运动与磁场状态
应用通过 Core Motion 读取重力、转动速率、磁场和校准状态，计算倾斜及环境提示。它不使用这些信息分析健康状况、日常运动习惯或广告兴趣。
系统语言与本地设置
首次使用时读取系统首选语言，以选择默认简体或繁体显示。你的手动语言、主题、北向基准、盘层组合与浏览分组、盘面显示偏好、震感、光影，以及奇门启用状态和起局参数通过系统本地偏好存储保存，不发送给开发者。
设备运行时间
应用使用设备运行时间进行采样和界面计时；开发调试版本的连续点击入口也用它计算点击间隔。这项信息仅用于 App 内事件计时，不用于设备指纹识别或跨应用追踪。

位置精度的边界：系统提供的位置可能包含精确经纬度，具体受你的授权和系统条件限制。奇门起局可使用并保存系统返回的经纬度；界面显示位数的限制不代表保存前已经降低坐标精度。当前实现仅在设备上使用，不传给开发者、不写入位置轨迹；关闭精确位置时，不尝试从其他来源还原精确位置。

未要求的个人资料：当前 App 不读取通讯录、相册、麦克风或摄像头，不要求身份证件、支付卡资料或广告标识符。你主动截屏、使用邮件或 Apple 反馈渠道发送附件属于另行发起的操作；附带内容以你实际选择及平台处理为准。

03

权限、选择与撤回

定位权限由 iOS 管理。应用仅在相关功能需要时请求使用期间定位，不请求为了营销而定位，也不提供后台追踪功能。拒绝定位不会阻止可用的磁北功能，也不影响手动选择地区或输入坐标进行奇门排盘，但真北、磁偏角和奇门自动定位可能不可用。

你可以随时在 iPhone 的系统设置中调整定位权限；系统提供的运动与健身、分析共享等选项也由你控制。不同 iOS 版本与设备显示的选项可能不同。如果关闭某项功能所需权限或设备不支持相关数据，应用会提示不可用或留空。

应用进入后台会停止位置、朝向与运动更新。撤回权限后不会继续通过该权限获取新的数据；当前会话中已收到的临时数据可能在更新、状态重置或进程结束时被替换或释放。奇门单次定位在取得结果、失败、取消、离开参数页或进入后台时停止；关闭奇门模块不会撤回系统定位授权，罗盘已获授权的前台定位仍可能运行。撤回定位权限或关闭模块不会自动删除此前保存的起局地与参数。你无需创建账号或提交个人联系方式来使用罗盘和奇门。

“仅允许一次”属于临时授权，后续可能需要重新选择；系统总定位开关、屏幕使用时间或设备管理限制也可能影响可用性。定位授权与网络连接是不同事项：没有网络并不等于撤回定位，切回磁北也不等于停止已授权的前台位置更新。具体选择见 Apple 的位置权限说明。

04

保存位置、期限与删除

实时读数：普通测量数据主要保留在运行内存中，用于当前显示与有效性判断。锁定读数仅保留当前会话快照，不建立长期测量档案。应用不会把位置轨迹或连续朝向历史写入开发者数据库。

奇门起局参数：启用奇门后，可选择自动定位或手动模式。自动定位模式在每次实际起局前获取一次位置；手动模式可选择地区、输入坐标，或主动点击定位取得当前起局地。定位失败时不沿用旧坐标起局。起局更新可另选自动或手动；自动更新仅在前台奇门盘、未锁定且未进入设置时，按时辰或节气变化重新起局，配合自动定位时会为该次起局更新位置，不进行后台追踪。真太阳时根据所选经度在本机计算，不请求逆地理编码或上传地点。

参数与地点记忆：成功应用盘局时在本机保存起局时刻、盘式、规则、自动／手动选项、真太阳时与重新起局确认开关，以及地点名称、地址描述（如有）与经纬度；新参数覆盖上次参数，不建立连续盘局历史。在“地区或坐标”页面确认的手动地点另有独立记忆，即使随后取消参数页，该地点记忆仍可能保留；直接点击“使用当前定位”的结果在成功应用后随当前参数保存。自动定位更新不会覆盖独立的手动地点记忆。

清除起局地：在参数页切到手动、清除地点并成功应用后可移除当前参数中的地点；手动记忆保留至再次选择覆盖或删除 App 数据。关闭奇门模块保留上述设置与地点，并不等同于删除。相关数据可能随 iOS 应用备份保存。

本地偏好：界面与盘层设置在本机持续保存，直到你修改设置或删除相应应用数据。iOS 可能按照你的设备备份设置备份应用容器；开发者不运营独立的同步服务器，也无法远程读取或删除你的系统备份。

本地诊断：开发调试版本在专门的诊断启动方式下可以生成本地诊断文件，包含采样次数、读数、误差、传感器状态和时间等排查信息。该文件不会自动上传；普通使用没有自动发送诊断文件的功能，正式分发版本不包含该开发调试入口。只有你主动提供时，开发者才会收到相应内容。

删除方式：在 iOS 存储设置中使用“删除 App”可移除其本地应用数据；“卸载 App”可能保留文稿与数据。备份副本由你在 Apple 的相关设置中管理，恢复旧备份后部分设置也可能恢复。应用没有账号，因此没有单独的账号注销步骤。

诊断文件的边界：当前诊断方式按最新状态覆盖同一个本地文件，不持续追加位置轨迹；文件字段包括朝向、误差、磁场、倾斜、授权状态、警告、时间及显示性能计数，不含经纬度字段。退出诊断运行并不保证删除此前文件；它可继续留在 App 容器中，直到被覆盖、相应数据被移除或删除 App。若你曾导出或发送副本，副本须在对应设备、邮箱或平台分别管理。

删除不是跨服务联动：删除 App 不会自动删除已经发出的邮件、TestFlight 反馈、GitHub 记录、系统备份或你自行保存的截图。清除浏览器缓存也不会删除 App 本地偏好或平台服务器记录。开发者无法远程清理你设备、收件人的邮箱或独立平台的数据。

05

主动联系时的信息

当你向支持邮箱发送邮件时，开发者会收到发件地址、邮件正文，以及你选择附加的截图或文件。用途是回复问题、核实故障和处理你提出的请求；不会因此将你加入营销名单，也不会把邮件内容出售给广告方。

请尽量只提供设备型号、系统版本、App 版本和复现步骤。不要发送密码、验证码、身份证件、支付资料或与问题无关的精确位置。如误发了敏感内容，可继续通过同一邮箱提出删除请求。

支持沟通仅在处理请求及合理后续排查所需期间保留；不再需要时删除或去除可识别信息。若法律要求保留必要记录，或存在尚未解决的争议，可保留必要部分。你可以询问相关记录的处理情况，并请求删除不再必要的支持邮件或附件。

对于开发者另行保留的测试排查资料，同样按问题处理需要控制保留范围，不为营销或建立长期个人画像保存。问题解决且无必要继续保留时，删除或去除可识别信息；Apple、GitHub 与邮箱平台自身的保留周期由对应服务管理。你可以要求核对开发者目前持有哪些与你有关的资料及保留原因。

06

Apple、网站托管与外部链接

Apple 服务：定位与传感器由 Apple 系统框架提供；系统可能根据你的设置处理定位、备份或诊断信息。正式分发版本的 Apple 诊断与备份受相应系统设置及平台规则管理；TestFlight 的测试数据处理另见下文，不能因为 App 未接统计 SDK 就认为测试平台也不收集信息。你可查阅 Apple 隐私政策及 TestFlight 中的说明。

本支持网站：页面托管于 GitHub Pages。我们未在页面中加入广告、统计像素、分析脚本、注册表单或追踪 Cookie，也不使用浏览器本地存储建立访问画像。访问网页时，GitHub 作为托管服务会接收网络请求；GitHub 说明会为安全目的记录访问者 IP 地址。其处理方式见 GitHub 隐私声明。

邮件服务：主动发出的支持邮件经由你选择的邮件服务和支持邮箱服务商传递与保存。该处理由相应服务的隐私规则约束，开发者只使用收到的内容处理你的请求。

资料链接：应用和本网站含有测量资料、平台帮助、政策及其他应用的 App Store 推荐链接。App 内“使用与支持”“隐私政策”“用户协议”先询问是否打开外部网页；“知卜”推荐直接打开 App Store。打开后会连接相应网站，对方可能接收 IP 地址、浏览器信息及网络请求。外部网站的内容和隐私实践由其运营方负责，发送信息前请查看其说明。

TestFlight 测试版：根据 Apple 的 TestFlight 隐私说明，测试期间的崩溃日志及使用信息会由 Apple 自动收集并向开发者提供，不能在继续测试的同时选择退出这项收集。相关信息可包含设备与系统、安装及会话情况；姓名和邮箱的可见性取决于邀请方式。仅通过公开链接加入时，姓名和邮箱不向开发者显示，但你主动发送的反馈内容仍可能透露身份。反馈及截图由你主动提交。开发者仅将这些测试资料用于测试、排查和改进应用，不转交第三方。停止测试不会自动抹去已有记录。

浏览器与邮件链接：打开帮助网页时，浏览器可能在本机保存访问历史或缓存，这是浏览器行为，不是 App 建立测量档案。网页地址不附带 App 的朝向、经纬度或设备标识参数。点击邮箱链接只发起邮件撰写或调用邮件应用，不会由网页自动发送邮件；如果你最终发送，邮箱服务会按其规则处理正文及附件。

公开仓库：支持网站的 GitHub 仓库是公开的。在公开 Issue 或评论区发布内容可能被他人查看、复制或被搜索引擎收录。请勿在那里发布私人日志、位置或身份资料；私人支持请求请使用本页最后的邮箱。移除原帖也不能保证清除他人已保存的副本。

07

共享、安全与跨地区处理

当前 App 没有向开发者后台上传测量数据的接口，不出售或出租你的个人信息，不用于广告追踪。对于主动支持沟通，只有处理问题所必需的人员或提供传递、存储的服务才可能接触内容；如依法必须回应合法请求，仅提供所需范围内的信息。

应用使用 iOS 的权限机制和应用容器保存本地数据；网站使用 HTTPS 访问。请保护设备密码、Apple 账户和邮件账户。任何设备或网络系统都无法承诺绝对安全，因此反馈时应避免发送不必要的敏感信息。

App 的测量处理在你的设备上完成。网站托管、Apple 平台和邮件服务可能在你所在地区以外的服务器上处理网络或支持沟通信息；开发者不建立独立的跨境测量数据库。相关平台的具体处理安排由其政策说明。

08

你的请求与未成年人信息

你可控制系统权限，修改本地偏好，删除应用及本地数据，并就主动发送给开发者的支持资料提出访问、更正或删除请求。由于开发者不能读取你的设备数据，涉及设备偏好、Apple 备份或平台诊断的操作，需要你在对应系统或服务中完成。

为避免误删他人信息，处理邮件记录请求时可能需要你从原联系邮箱发起或提供足以定位该次沟通的说明；不会仅为处理普通支持请求索取身份证件。无法立即完成的请求，会说明原因和可行处理方式。

应用不针对未成年人建立资料或投放定向广告，也不要求用户填写出生日期。未成年人发送反馈前应获得监护人的适当协助。若你认为支持邮件中包含不应保留的未成年人信息，请告知以便核查和处理。

请求应发给谁：涉及开发者已收到的支持邮件或 TestFlight 资料，请通过末尾邮箱说明请求类型、相关版本或沟通日期；无须为了查询本机传感器记录额外发送身份文件。涉及 Apple 账号及平台保存的数据，可同时使用 Apple 数据与隐私渠道；涉及 GitHub 托管记录，请按其隐私声明中的渠道联系。开发者仅能处理自己控制的记录，无法保证替平台执行删除。

访问、更正、删除、限制处理、提出异议或投诉等权利的适用范围取决于你所在地的法律和具体处理情况。收到请求后会核实必要范围并回复处理结果；若需要更多信息、涉及他人权益或存在依法保留的部分，会说明理由。不会以本页文字缩减依法享有的权利，也不会承诺所有记录都能立即、无条件删除。
